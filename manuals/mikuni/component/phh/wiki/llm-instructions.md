# Mikuni PHH manual — lookup guidance

This is a **component manual** for the Mikuni 40PHH and 44PHH carburetors. The vehicle
application table on PDF p.30 does not make any setting universal to a vehicle or
engine. Check the exact carburetor variant and table row.

Start with [the chapter index](00-index.md), then use the page-linked chapter text.
Every PDF page is also available as an image in [all-files.md](all-files.md).
The [exploded overview](08-exploded-overview.md) has a separate high-resolution image.

The chapter text is the PDF's **unedited OCR layer**. It is searchable, but tables,
part numbers, and numeric settings have recognition and column-alignment errors.
Open the linked page image before giving any value or procedural detail. Do not
report a value as verified merely because it appears in the OCR. The machine
specification index is intentionally empty until values are checked against images.

Cite the source PDF page number (`[PDF p.N]`) when answering. If a value is unclear
in the page image, say so and do not guess.
