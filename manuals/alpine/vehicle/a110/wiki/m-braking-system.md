## M-2 — Characteristics

<a id="p50"></a>
### Front brakes

- Disc brakes, floating **"BENDIX"** calipers, one piston with automatic adjustment.

| Item | Value |
| ---- | ----- |
| Ø of cylinder | 38 mm |
| Ø of disc | 261 mm |
| Disc thickness | 7.5 mm |
| Pad thickness | 9.5 mm |
| Braking track width | 40 mm |
| Rubbing surface of linings (for 2 wheels) | 140 cm² |
| Pad type | Ferodo **736** (**733** on version 85) |

<a id="p50"></a>
### Rear brakes

- Disc brakes, floating **"BENDIX"** calipers, one piston with automatic adjustment.
- Handbrake acting on the calipers.
- Brake proportioning valve only on versions **85** and **1300 G**.

| Item | Value |
| ---- | ----- |
| Ø of cylinder | 32 mm |
| Ø of disc | 261 mm |
| Disc thickness | 7.5 mm |
| Pad thickness | 9.5 mm |
| Braking track width | 40 mm |
| Rubbing surface of linings (for 2 wheels) | 140 cm² |
| Pad type | Ferodo **736** (**733** on version 83) |

> **Proportioning valve:** only fitted on the **85** and **1300 G** versions and on vehicles
> equipped with **hydrovac**.

### Master cylinder

- **Ø 19 single** for version **85**.
- **Ø 19 tandem** for versions **1300 G, 1300 S, 1600 S** (master cylinder of R 1190 type
  U.S.A.).

Brake fluid standard: **GIRLING AMBER**.

> **IMPORTANT:** No other liquid is miscible with it.

### Brake cooling (note)

Some versions, depending on their use, have brake cooling shields allowing better cooling
of … . The rear ones may also be deleted to facilitate pad changes in competition.
Extensions are available for the front and rear hoses in order to accelerate the dispersion
of heat caused by brake heating.
