# Honda S2000 service manual — text for Gemini

This branch contains the reviewed text and indexes for the 2000–2008 Honda S2000 AP1/AP2 service manual, covering 1,970 PDF pages in 27 chapters. It is a small text-only snapshot for Gemini's GitHub Import code feature. The complete illustrated publication is [here](https://github.com/spacecowboyian/oio-shop-shelf/tree/manuals-s2000/manuals/honda/vehicle/s2000).

Start at [the chapter index](manuals/honda/vehicle/s2000/wiki/00-index.md). Each page marker links to the corresponding original page image in the published manual. The images and curated diagrams are linked from the text but are not duplicated in this import branch. The source PDF and raw OCR are private.

When answering a repair question, identify the applicable model years, use the relevant chapter, give the printed and PDF page numbers, and link the page image. Say when the source is ambiguous or when a detail cannot be verified. Do not invent steps, measurements, or safety instructions.

This snapshot corresponds to [release manuals-s2000](https://github.com/spacecowboyian/oio-shop-shelf/releases/tag/manuals-s2000).
